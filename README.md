# Frame Innovations: The WorkCell site

The product site for **The WorkCell**, served at [frameinnovations.com](https://frameinnovations.com) on Cloudflare Pages.

## Layout

| Path | What it is |
| --- | --- |
| `site/` | Everything Cloudflare serves. **This is the Pages build output directory.** |
| `site/index.html` | The page. Generated; edit `src/index.src.html` instead. |
| `site/_worker.js` | Waitlist API (`POST /api/waitlist`, `GET /api/waitlist.csv?key=…`), then static files. |
| `site/wc-model.txt` | The WorkCell 3D model (GLB, base64). |
| `site/workcell-spec-sheet.pdf` | Spec sheet download. Generated by `tools/specpdf.py`. |
| `site/_headers` | Cache and download headers. |
| `src/index.src.html` | Page source (HTML, CSS and JS in one file). |
| `src/logo_line.txt` | Traced WorkCell logo outline, inserted at the `/*LOGO*/` marker. |
| `tools/build.py` | Builds `site/index.html` from `src/`. |
| `tools/specpdf.py` | Builds the spec sheet PDF (needs `pip install reportlab`). |

After editing anything in `src/`, run `python3 tools/build.py` and commit both the source and `site/`.
Cloudflare redeploys automatically on every push to `main`.

## Cloudflare Pages settings

- **Framework preset:** None
- **Build command:** *(empty)*
- **Build output directory:** `site`
- **Bindings:** D1 database `waitlist` bound as `DB`
- **Secrets:** `EXPORT_KEY`, any long random string

The worker creates the `waitlist` table on the first sign-up. Download every sign-up as CSV at
`https://frameinnovations.com/api/waitlist.csv?key=<EXPORT_KEY>`, or query it in the dashboard
(D1 → waitlist → Console: `SELECT * FROM waitlist ORDER BY created_at DESC`).
